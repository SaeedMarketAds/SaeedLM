# SaeedLM

An independent experimental language-model project.

## Current status

- Experimental bigram model
- Tokenizer and encoded corpus
- Basic training and text generation scripts
- Learning journal for recorded knowledge and experiments

Recording knowledge does not itself update model weights.
Training improvements must be verified through reproducible tests.

## Current scope

SaeedLM is developed independently from the SaeedMarketAds application.
External AI APIs are not required by the project design.
