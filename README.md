# SaeedLM

**An Independent Arabic Language Model, developed step by step.**

SaeedLM is an independent experimental language-model project, developed separately from the SaeedMarketAds application.

## Current Status

- Experimental bigram language model
- Tokenizer and encoded corpus
- Basic training and text generation scripts
- Learning journal for recorded knowledge and experiments

## Project Principles

- Independent development
- No external AI API required by the project design
- Gradual improvement through experiments and testing
- Reproducible evaluation of model quality

Recording knowledge in the learning journal does not itself update model weights. Training improvements must be verified through reproducible tests.

## Project Structure

- `tokenizer/` — Tokenizer and encoding tools
- `model/` — Model training and text generation
- `learning/` — Learning journal
- `dataset/` — Training corpus and tokenized data
